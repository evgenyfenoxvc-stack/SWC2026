# SWC2026 — сборка через Codemagic (без Mac)

Этот способ собирает приложение в облаке, устанавливает в облачный
симулятор и делает скриншот работающего приложения — Mac не нужен.

## Шаг 1. Загрузите код на GitHub

1. Зайдите на github.com → **New repository**
2. Название: `SWC2026` (можно private)
3. Не добавляйте README/gitignore при создании — оставьте пустым
4. У себя на компьютере (Windows/Mac/Linux — любой) распакуйте архив
   `SWC2026.zip` и выполните в папке проекта:

```bash
cd SWC2026
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/SWC2026.git
git push -u origin main
```

(Замените `ВАШ_ЛОГИН` на свой GitHub username. Если Git не установлен —
можно и через веб-интерфейс GitHub: "Add file → Upload files" и
перетащить все файлы из папки.)

## Шаг 2. Подключите репозиторий к Codemagic

1. Зайдите на **codemagic.io** → Sign up (можно через GitHub-аккаунт,
   это займёт секунды)
2. **Add application** → выберите GitHub → выберите репозиторий `SWC2026`
3. Codemagic автоматически найдёт файл `codemagic.yaml` в корне репозитория
   — конфигурация сборки уже готова, ничего настраивать не нужно

## Шаг 3. Запустите сборку

1. Нажмите **Start new build**
2. Выберите workflow **"SWC2026 - Simulator Screenshot"**
3. Нажмите **Start build**
4. Сборка займёт 5-10 минут — можно следить за логом в реальном времени

## Шаг 4. Посмотрите результат

После завершения сборки откройте вкладку **Artifacts** — там будут:
- `screenshot_1.png` и `screenshot_2.png` — снимки экрана приложения
  с загруженным сайтом
- `.app` файл сборки (для дальнейшего использования)

## Что дальше

- **Бесплатный лимит**: 500 минут сборки в месяц на бесплатном тарифе —
  этого хватит на десятки таких сборок
- **Реальный iPhone**: для установки на физическое устройство или
  публикации в App Store всё равно потребуется Apple Developer аккаунт
  ($99/год) — это ограничение Apple, Codemagic его не обходит
- Если что-то пойдёт не так на любом из шагов — пришлите текст ошибки
  из лога сборки, разберём вместе
